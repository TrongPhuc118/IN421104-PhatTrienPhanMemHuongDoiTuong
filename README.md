# Sổ tay nông nghiệp

## Giới thiệu
Ứng dụng quản lý mùa vụ, vật tư, nhật ký canh tác,
chi phí và doanh thu.

## Công nghệ
- C#
- .NET 10
- Object-Oriented Programming

## Cấu trúc
- SoTayNongNghiep.Domain
- SoTayNongNghiep.Console

## Cách chạy
dotnet build SoTayNongNghiep.slnx
dotnet run --project src/SoTayNongNghiep.Console
